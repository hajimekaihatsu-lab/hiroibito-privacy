プライバシーポリシー

アプリ名：拾人 -ひろいびと- 〜神造武具トレハン・ハクスラRPG〜
デベロッパー：hajime kaihatsu
制定日：2026年9月7日／最終更新：2026年9月7日

本ポリシーは、hajime kaihatsu（以下「当開発者」）が提供する Android アプリケーション「拾人 -ひろいびと-」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

本アプリは、利用者の個人情報を一切収集しません。

本アプリは端末内で完結して動作し、以下のいずれも行いません。

  • 氏名・メールアドレス・電話番号・住所などの個人情報の取得
  • 位置情報の取得
  • 連絡先・写真・カメラ・マイクへのアクセス
  • 広告識別子（広告ID / AD_ID）の取得および利用
  • 利用状況・行動履歴の解析および外部への送信
  • アカウント登録またはログイン

2. セーブデータの取り扱い

ゲームの進行状況（到達階層、所持品、キャラクターの成長状況など）は利用者の端末内にのみ保存され、外部のサーバーへ送信されることはありません。当開発者がこれらのデータを閲覧・取得することはできません。

3. 情報の保持と削除

保持される場所利用者の端末内のみ
保持期間本アプリが端末にインストールされている間
削除の方法本アプリをアンインストールする、または端末の「設定 → アプリ → 拾人 → ストレージ → データを削除」を実行することで、保存されたすべてのデータが削除されます
削除の申請データは当開発者の管理下に存在しないため、削除を当開発者に申請する必要はありません

4. 情報の安全な取り扱い

本アプリは外部との通信を行わず、利用者の情報を送信・保管しません。そのため、通信経路上またはサーバー上での情報漏洩のリスクは存在しません。端末内のデータは、Android の標準的なアプリケーションサンドボックスによって他のアプリから保護されます。

5. 第三者への提供

収集する情報が存在しないため、第三者への提供・販売・共有は一切行いません。

6. 第三者サービスの利用

現在のバージョンでは、広告配信サービス、アクセス解析サービス、クラッシュレポートサービスを含む、いかなる第三者サービスも利用していません。

将来、広告配信サービス等を導入する場合は、本ポリシーを事前に更新し、取得される情報の種類と利用目的を明記します。

7. 子どものプライバシー

本アプリは個人情報を収集しないため、年齢を問わず安全にご利用いただけます。13歳未満の利用者から意図的に個人情報を収集することはありません。

8. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて変更されることがあります。重要な変更を行う場合は、本ページ上で改定日を更新して周知します。

Privacy Policy

App: Hiroibito
Developer: hajime kaihatsu
Effective: September 7, 2026 / Last updated: September 7, 2026

1. Information We Collect

This app does not collect any personal information. It runs entirely on the user's device and does not collect names, email addresses, phone numbers, addresses, location data, contacts, photos, camera or microphone data, advertising identifiers (AD_ID), or usage analytics. No account registration or sign-in is required.

2. Save Data

Game progress is stored only on the user's device and is never transmitted to any server. The developer cannot access this data.

3. Data Retention and Deletion

Data is retained on the device only while the app is installed. Users can delete all stored data by uninstalling the app, or via Settings → Apps → Hiroibito → Storage → Clear data. No deletion request to the developer is necessary, as the developer holds no user data.

4. Security

The app does not communicate with external servers and does not transmit or store user information. On-device data is protected by Android's standard application sandbox.

5. Third Parties

No information is shared, sold, or disclosed to third parties. The current version uses no third-party services, including advertising networks, analytics, and crash reporting. If such services are introduced in the future, this policy will be updated beforehand.

6. Children's Privacy

This app collects no personal information and is safe for users of any age. We do not knowingly collect personal information from children under 13.
